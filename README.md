# 🎮 Game Activity Analysis Dashboard

## 📌 Project Overview

This project analyzes player activity and engagement using Tableau. The dashboard provides insights into user activity, Battle Pass adoption, and average play time across different player groups.

The analysis uses calculated fields and interactive filters to make player behavior easier to explore.

---

## 🎯 Business Objective

The dashboard was created to answer the following questions:

- How does the number of active players change over time?
- What percentage of players use a Battle Pass?
- How much time does an average player spend in the game?
- How does average play time vary across age groups and time periods?

## 📊 Dashboard Features

- Monthly unique player analysis
- Battle Pass adoption rate
- Average play time per player
- Play time analysis by age group and quarter
- Interactive filters for date, age group, activity, language, and game
- Calculated fields for player-level metrics
